# Sport – Mitarbeit erfassen

Offline-Web-App fürs iPhone zum schnellen Erfassen der Mitarbeit im Sportunterricht.

- Enthält **keine Schülerdaten**. Alle Daten bleiben ausschließlich auf dem Gerät (Browser-Speicher der App).
- Schülerlisten kommen per AirDrop-Datei aus dem Mac-Tool, die erfassten Stunden gehen per AirDrop zurück.
- Installation: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
